## 二、已修复/已闭环问题

### R23-01 版本管理“重新编辑”按钮样式与同区操作按钮不一致

- **现象：**
  - 版本管理列表（订阅 / 规则 / 分享 / 自定义共用 `VersionManageView`）中，装配蓝图版本的「重新编辑」按钮使用 `<Button type="link">` 文字链接样式；
  - 同一操作区旁边的「预览 / 编辑 / 激活分发 / 删除」均为普通 `size="small"` 按钮，视觉风格不一致。
- **根因：**
  - `frontend/src/views/admin/VersionManageView.vue` 中「重新编辑」按钮显式设置了 `type="link"`，未遵循同列操作按钮的默认样式。
- **影响范围：**
  - 仅影响版本管理页操作区 UI 风格，不影响「重新编辑」跳转逻辑与后端接口。
- **修复方案（用户已确认）：**
  - 将「重新编辑」按钮改为普通 `size="small"` 按钮，与「预览 / 编辑」等操作按钮保持一致。
  - 移动端「更多 ▾」菜单中的「重新编辑」保持现状，不在本次调整范围内。
- **涉及文件：**
  - `frontend/src/views/admin/VersionManageView.vue`
- **验证：**
  - `cd frontend && npm run build` 通过（vue-tsc + vite build）。
- **状态：** ✅ 已修复（2026-08-27）

### R23-02 首页分流规则卡片空态/有值态展示风格与复制操作待优化

- **现象：**
  - 未设置首页默认分流规则时，卡片仅在小字「管理员暂未设置分流规则」+ 常驻说明行中展示，缺少直达使用引导；
  - 已设置首页默认分流规则时，规则名称/版本与长 URL 输入框 (`CopyField`) 挤在同一行，复制操作不够醒目，文案位置偏挤。
- **根因：**
  - `frontend/src/views/HomeView.vue` 的分流规则卡片未按“空态 / 有值态”区分布局，且复用了长链接输入框展示方案。
- **影响范围：**
  - 仅影响用户首页分流规则卡片的展示与复制体验，不影响后端接口与下载链接逻辑。
- **修复方案（用户已确认）：**
  - **空态：** 居中大标题「分流规则为 Shadowrocket 客户端专用」+ 居中灰色说明「使用指引：先添加订阅获取节点，再导入分流规则」。
  - **有值态：** 左侧保留「分流规则」+ 规则名称 + 当前版本；右侧改为醒目的主按钮「复制规则链接」，不再展示长 URL 输入框；指引文案仅在空态展示。
  - 卡片点击跳转 `/rules` 与按钮区域 `@click.stop` 保持现有行为。
- **涉及文件：**
  - `frontend/src/views/HomeView.vue`
  - `Design2-UI.md`（§3.1.2 同步规格）
- **验证：**
  - `cd frontend && npm run build` 通过（vue-tsc + vite build）。
- **状态：** ✅ 已修复（2026-08-27）
