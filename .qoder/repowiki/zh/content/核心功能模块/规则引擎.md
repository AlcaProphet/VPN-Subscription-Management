## 简介
本文件面向"分流规则"的完整生命周期与运行机制，覆盖以下主题：
- 规则管理：创建、改名、删除、版本管理与预览
- **自动标识生成系统**：rule- 前缀 + 8位随机短码，事务内冲突解决与回滚机制
- 规则语法与动态生成：支持文本编辑与文件上传两种模式；YAML 启发式校验提示
- 优先级与匹配逻辑：当前实现以"规则集合 + 客户端类型 + scheme 模板"为主，未内置复杂匹配引擎
- 规则与订阅的关联：通过"全局标识 slug 跨四类资源唯一"进行命名空间隔离；规则本身不直接绑定订阅
- 测试与调试：预览接口、前端弹窗、错误码映射
- 性能优化建议与最佳实践

## 详细组件分析

### 规则服务（rule.Service）
- 职责
  - 创建规则：名称必填、客户端类型限制为 shadowrocket；**slug为空时自动生成（rule- 前缀 + 8位随机短码）**，并在事务内完成跨四类资源的唯一性检查
  - 首版本创建：在规则创建后立刻建立首个版本，失败则回滚规则与 Token
  - 改名：仅允许修改名称，client_type 与 schemes 创建后不可改
  - 列表/详情：返回规则基本信息、当前版本号、全局 Token 与刷新时间
  - 删除：级联删除 Token、版本记录与文件目录
  - Token 轮替：物理替换旧 Token，更新 refreshed_at

- 关键数据结构
  - Rule：包含 ID、slug、name、client_type、schemes、token、current_version、created_at、refreshed_at

- 事务与一致性
  - 创建流程使用 BEGIN IMMEDIATE 事务保证原子性
  - **标识生成在事务内进行，冲突自动重试最多3次**
  - 首版本创建失败时执行回滚，清理已创建的规则与 Token

### 标识生成器（slug.Generate）
- 职责
  - **自动生成规则标识**：生成 rule- 前缀 + 8位加密安全随机短码
  - **冲突解决机制**：最多重试3次，仍冲突则报错并记录日志
  - **字符集优化**：使用易混淆字符排除的字符集（abcdefghjkmnpqrstuvwxyz23456789）
  - **事务安全**：在数据库事务中执行，确保并发安全

- 生成算法
  - 使用 crypto/rand 生成加密安全随机数
  - 从自定义字符集中选择8个字符
  - 格式：`rule-` + 8位随机短码（如 `rule-a3k9m2x7`）
  - 冲突检测：查询四类资源表（subscriptions、rules、custom_subscriptions、share_subscriptions）

- 错误处理
  - 连续冲突超过3次：返回错误并记录日志
  - 随机数生成失败：返回具体错误信息

## 性能考量
- 版本上限与驱逐
  - 每份资源最多保留 5 个版本，超出时自动驱逐最旧版本（不含当前激活），避免无限增长
- 文件大小限制
  - 上传内容与文本编辑均受 ≤50MB 限制，防止内存与磁盘压力
- 事务与锁
  - 版本创建与切换使用 BEGIN IMMEDIATE 事务与库级写锁，保证并发安全
  - **标识生成在事务中进行，避免并发冲突**
- 启动自检
  - 启动时重建 symlink，确保 DB current_version 与文件指针一致
- 缓存控制
  - 预览接口设置 no-store，避免敏感内容被缓存
- **标识生成性能优化**
  - 随机短码生成使用加密安全随机数，质量高且速度快
  - 冲突检测使用单次数据库查询，支持快速失败
  - 最多3次重试机制，平衡成功率与性能

## 故障排查指南
- 常见错误与定位
  - 参数错误（400）：名称为空、客户端类型不支持、schemes 格式错误、内容过大
  - 冲突（409）：slug 已被其他三类资源占用（手动输入时）
  - 不存在（404）：规则或版本不存在
  - 内部错误（500）：数据库或文件系统异常
  - **标识生成失败**：连续冲突超过3次，需检查系统负载

- 调试方法
  - 使用预览接口查看当前版本内容（会话凭据，text/plain）
  - 检查 Token 刷新时间，确认轮替是否生效
  - 前端弹窗显示错误消息，结合后端日志定位问题
  - **检查标识生成日志**：查看是否有冲突重试记录

### 自动标识生成系统详解

**核心特性**：
- **自动生成**：rule- 前缀 + 8位加密安全随机短码
- **冲突解决**：最多重试3次，确保标识唯一性
- **事务安全**：在数据库事务中执行，保证并发安全
- **字符集优化**：排除易混淆字符，提高可读性

**生成算法**：
```mermaid
flowchart TD
A[开始生成] --> B[生成8位随机短码]
B --> C[组合: rule- + 短码]
C --> D{检查冲突}
D --> |无冲突| E[返回标识]
D --> |有冲突| F{重试次数 < 3}
F --> |是| B
F --> |否| G[返回错误]
```

**字符集设计**：
- 使用 `abcdefghjkmnpqrstuvwxyz23456789` 字符集
- 排除易混淆字符：i, l, o, 0, 1
- 混合字母和数字，提高熵值

**错误处理**：
- 随机数生成失败：返回具体错误信息
- 连续冲突超过3次：记录日志并返回友好错误
- 数据库查询失败：返回详细的错误上下文
