测试以独立 spec 文件组织，每个文件聚焦一个业务域：auth-store.spec.ts 验证登录/注册/登出对 Pinia store 与 localStorage 的影响；home-view.spec.ts、form-submit.spec.ts、theme.spec.ts、import-url.spec.ts 使用 @vue/test-utils 的 mount 挂载组件并断言渲染结果；router-guard.spec.ts 与 request.spec.ts 分别验证路由守卫重定向与 axios 拦截器的 401 处理。所有测试通过 setup.ts 在 jsdom 环境中补齐 AntD 所需的 matchMedia、getComputedStyle 等浏览器 API。依赖方向单向：测试 → 应用源码（@/stores/*、@/views/*、@/api/*、@/router），外部 HTTP 与路由通过 vi.mock 注入 mock，避免真实网络与浏览器环境耦合。
