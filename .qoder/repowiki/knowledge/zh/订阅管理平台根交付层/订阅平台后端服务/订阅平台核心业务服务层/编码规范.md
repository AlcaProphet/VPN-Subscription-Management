- 每个包暴露一个 Service struct 并通过 NewService 构造函数注入 store、versions、tokens、log 等依赖，方法全部以 *Service 接收者定义。
- 业务错误统一以包级 var errors.New(...) 声明（如 ErrNotFound、ErrBadRequest），上层通过 fmt.Errorf("%w: ...") 包装后由接入层映射 HTTP 状态码。
- 所有写操作通过 store.TxImmediate 包裹事务，失败时调用独立的 rollbackRecord/rollbackEmptyRecord 辅助函数回滚已插入的记录。
- 列表返回空切片而非 nil（out := make([]T, 0)），保证前端 .map 安全。
- slug 自动生成统一调用 subscription.GenerateSlugTx 或 slug.Generate，并传入 "subscription-"/"rule-"/"custom-"/"share-"/"group-"/"platform-" 前缀，冲突自动重试。
- 删除流程遵循「事务内收集文件路径 → 提交后 os.Remove 仅记日志」模式，确保 DB 删除成功即视为整体成功。
