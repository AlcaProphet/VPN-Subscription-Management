本模块由六个相互协作的 internal 子包构成，依赖方向自下而上：store → config → (ratelimit, oidc) → response/slug。
- store：基于 modernc.org/sqlite（零 CGO）的单写者模型封装，开启 WAL、外键与 busy_timeout；通过 `Migrate` 按 `NNNN_name.sql` 文件名顺序执行版本化迁移，并维护 `schema_migrations` 表防止回滚；`TxImmediate` 借助 DSN `_txlock=immediate` 实现 BEGIN IMMEDIATE 先读后写事务，供冲突检测场景使用。
- config：以 `system_config` 表为唯一配置源，暴露 Service 提供 Get/Set/GetBool/GetInt/GetJSONStringSlice 等类型化读取；敏感键通过 `RegisterSensitive` 注册，写入时经 HKDF-SHA256 从签名密钥派生 AES-256-GCM 密钥加密，读取时自动解密；`EnsureSigningKey` 在缺失时生成 32 字节随机密钥；export.go 提供 Argon2id + AES-GCM 的配置导出/导入能力，仅 prod 模式开放。
- ratelimit：基于内存 map 的 IP 固定窗口限流中间件，阈值从 config 动态读取（修改立即生效），按 scope|ip|minute 槽计数并定期 gc 清理过期桶。
- oidc：完整实现 OpenID Connect Authorization Code + PKCE S256 流程，包含发现文档缓存、state/code_verifier 持久化与用后即删、token 交换与 ID Token 解析、白名单角色/组匹配、mock 提供商支持；参数以 JSON 存于 system_config 并按 provider_type 隔离，client_secret 单独加密。
- response：独立 gin 响应助手，统一 `{code,message,data}` 结构，5xx 默认对外脱敏，调试模式可注入 debugProvider 返回真实错误。
- slug：为平台/分组/订阅等资源生成「前缀+8位安全随机」短码，内置白名单表查重与四表全局唯一性校验。
