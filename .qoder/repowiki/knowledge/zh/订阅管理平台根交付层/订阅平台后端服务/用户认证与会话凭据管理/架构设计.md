模块由三个相互协作的子包构成，依赖方向单向：`user` → `auth` + `token`，`auth` 通过接口反向依赖 `user`，`token` 仅依赖 `store`。
- `auth`（认证核心）：定义 `Service`，封装 bcrypt 密码哈希/校验、邮箱规范化、HS256 JWT 签发与解析；提供 `SessionMiddleware`（Bearer 解析→实时查库快照→比对 `credential_version`→校验 `active`）和 `AdminMiddleware`（角色拦截），并通过 `UserSource` 接口注入 `user.Service.SnapshotByID`，避免循环依赖。
- `user`（用户业务层）：`Service` 负责自注册（首管理员机制：空表判定+事务内置位 `admin_initialized`）、登录、快照查询；`AdminService` 实现五重保护（禁止操作自己、不能删除/禁用最后一个活跃管理员、待审批限制等），并在降级/禁用/删除时级联清理 Token 与版本文件。
- `token`（下载/分享/规则 Token 服务）：基于 `download_tokens`/`share_tokens`/`rule_tokens` 表实现三态复用键（无标识 user+platform / 自定义 custom_sub_id / 显式 subscription_id），在 `BEGIN IMMEDIATE` 事务内先查后建并带冲突重试；提供 Refresh/Rotate 轮替（旧删新写同事务）及按订阅/自定义/用户维度的级联删除。
- 跨包一致性：所有写操作统一通过 `store.TxImmediate` 保证串行化；敏感状态变更（密码重置、禁用、降级）在同一事务内递增 `credential_version` 使旧会话立即失效；邮件发送以函数注入方式预留 SMTP 接入点。
