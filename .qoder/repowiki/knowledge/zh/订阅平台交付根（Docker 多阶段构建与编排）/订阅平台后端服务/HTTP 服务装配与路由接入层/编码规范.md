- 每个业务域文件定义一个 `XxxHandler` 结构体承载依赖，并提供 `RegisterXxxRoutes(engine, h, ...)` 函数集中注册该域路由，Handler 与路由解耦。
- 路由注册时通过组合 `authSvc.SessionMiddleware()` 与 `auth.AdminMiddleware()` 作为中间件链，区分普通用户与管理员端点。
- 请求参数使用 struct + JSON tag binding（`ShouldBindJSON` / `ShouldBindBodyWithJSON`），并在 tag 中声明长度限制（如 max/min），绑定失败统一返回 400。
- 错误处理采用 `errors.Is(err, xxx.ErrXxx)` 分支映射到具体 HTTP 状态码，未知错误统一走 `Fail(c, http.StatusInternalServerError, err.Error())`。
- 成功响应统一通过 `OK(c, data)` 包装，列表响应统一使用 `ListData{List: list, Total: ...}` 包裹结构。
- 版本类端点（订阅/自定义/分享/规则）复用 `versionList/create/switch/preview/delete` 通用处理器，仅传入不同 `version.OwnerType`，禁止复制粘贴实现。
