根目录不承载业务逻辑，仅负责把 backend、frontend、docs_and_templates 三个子模块组装为单一容器镜像：Dockerfile 采用 node:22 编译前端至 /build/dist、golang:1.25-alpine 以 CGO_ENABLED=0 静态编译后端并通过 go:embed 将 dist 嵌入二进制、alpine:3.21 最小运行时仅执行 /server；docker-compose.yml 暴露 8080 端口、挂载 vpn-data:/data 持久化 SQLite 与 /public 资源，并通过 APP_MODE/LOG_LEVEL/TRUST_PROXY/RESET_ADMIN_PASSWORD 等环境变量注入配置；前后端无独立进程通信，Gin 路由同时承载业务 API 与前端 SPA 静态文件分发；.github/workflows/docker-build.yml 在推送 v* 标签时触发 CI 构建并推送镜像至 ghcr.io，.smoke-test.sh 配合 compose healthcheck 探测 /health 完成启动验证。
