- 组件统一使用 Vue 3 `<script setup lang="ts">` 语法并通过 `defineProps` / `defineEmits` 声明类型化接口。
- 全局通知统一通过 `Notify.success/error/warning/info/detail` 调用，禁止在业务代码中直接引用 `message.*` 或 `notification.*`。
- 暗色模式通过 `useTheme()` composable 读取/切换 `dark` ref，并以 localStorage 持久化状态，模板中使用 Tailwind `dark:` 前缀适配样式。
- 布局组件通过 `matchMedia('(max-width: 767px)')` 检测移动端，在桌面端使用 `Layout.Sider`、移动端使用 `Drawer` 实现响应式侧边栏。
- 列表数据展示统一使用 `TriStateList` 的 loading/empty/error/slot 四态结构，避免在各页面重复编写加载与空态逻辑。
- 危险操作统一通过 `ConfirmModal` 弹出确认框，支持 `danger` 红色按钮与可选的 `confirmWord` 输入校验，禁止使用浏览器原生 `confirm`。
