- API 层按领域拆分为独立 ts 文件，每个文件导出类型定义与一组同名函数（list/get/create/update/delete/batch*），统一通过 `http.get/post/put/delete` 调用 `/admin/*` 路径。
- 分页接口返回 `{ list, total }` 结构，调用方自行解构赋值到本地 `list`/`total` 响应式变量，并在加载时维护 loading 状态。
- 视图采用 ≥768px 表格态与 <768px 卡片态的双态渲染，通过 `md:block` / `md:hidden` 或 `window.matchMedia('(max-width: 767px)')` 切换布局。
- 危险操作（删除、拒绝、批量通过）统一通过 `ConfirmModal` 二次确认，并以 `loading` 绑定异步过程。
- 用户反馈统一通过 `@/components/Notify` 的 success/error 提示，错误捕获后取 `(err as Error).message` 展示。
- 列表数据加载放在 `onMounted` 中执行，并使用 try/catch/finally 包裹以确保 loading 状态复位。
