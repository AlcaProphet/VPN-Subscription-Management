- API 调用按业务域拆分到 `src/api/*.ts`，由视图直接 import 对应模块而非内联 axios 请求
- 视图按角色划分目录：`views/admin/` 存放管理后台页面，根级 `views/` 存放用户端页面，统一通过布局组件包裹
- 跨页面状态集中在 Pinia store（auth、system），视图通过 `useStore()` 访问而非本地 state
- 可复用的交互能力封装为 `components/` 中的 Vue 组件，供多视图复用
- 单元测试以 `.spec.ts` 文件集中放置于 `tests/`，针对 store、路由守卫、axios 拦截器等核心逻辑编写
