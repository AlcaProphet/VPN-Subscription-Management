模块按职责划分为两层：
- 视图层 `src/views/`：基于 Vue 3 `<script setup>` + Ant Design Vue 的页面组件。根目录存放公共页（LoginView/RegisterView/ForgotView/ResetView/OidcCallbackView/HomeView/EmergencyView/ProfileView/PendingView/SetupView/NotFoundView），`admin/` 子目录集中管理后台页面（UsersView、GroupsView、PlatformsView、RulesView、ApprovalsView、SubscriptionsView、SharesView、AssemblyView、SettingsView、LogsView、VersionManageView、PlatformEditView）。每个 View 通过 Pinia store（`useAuthStore`、`useSystemStore`）获取鉴权态与系统状态，并通过 `vue-router` 导航。
- API 层 `src/api/*.ts`：薄封装文件，统一通过 `./request` 导出的 `http` 实例调用后端 REST 端点，并按领域拆分（auth.ts、profile.ts、home.ts、emergency.ts、settings.ts、log.ts），仅暴露函数与 TypeScript 类型，不包含业务逻辑。
依赖方向单向：Views → stores + api/* → request；视图不直接操作 fetch，API 文件不引用任何 UI 组件。管理员视图集中在 `admin/` 下，普通用户视图位于 `views/` 根目录，体现权限分层的页面组织方式。
