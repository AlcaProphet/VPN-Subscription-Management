- 每个 API 文件以单行注释声明所属领域（如 `// api/auth.ts：认证接口封装`），并通过 `import { http } from './request'` 复用统一请求实例。
- 视图组件使用 `<script setup lang="ts">` 配合 `reactive`/`ref`/`computed` 管理表单与状态，所有异步操作包裹 try/catch/finally，并在 finally 中重置 loading 标志位。
- 用户反馈统一通过 `Notify.success/error/info` 或 `Alert` 组件展示，错误消息直接透传后端返回的 `err.message`。
- 危险操作（删除、禁用、吊销 Token、清除 OIDC 绑定等）通过 `ConfirmModal` 二次确认，并以 `danger` 属性高亮。
- 列表页采用「后端分页」模式：维护 page/size/total 响应式变量，监听查询条件变化触发 load()，并使用 AntD Table/Pagination 组合渲染。
- 移动端适配通过 `window.matchMedia('(max-width: 767px)')` 切换表格态与卡片态两种布局，在 onMounted/onUnmounted 中注册/移除 resize 监听。
