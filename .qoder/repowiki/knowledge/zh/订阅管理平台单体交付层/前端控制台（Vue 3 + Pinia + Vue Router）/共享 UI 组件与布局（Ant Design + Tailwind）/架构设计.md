模块按职责划分为四个并列子目录：`components/` 存放跨页面复用的原子组件，包括通用顶栏 `AppHeader.vue`（组合 `@/stores/auth`、`@/stores/system` 与 `useTheme` 实现站点名、角色标签、暗色切换）、统一消息封装 `Notify.ts`（集中调用 `message.*` / `notification.*`，禁止业务代码直接引用）、危险操作确认框 `ConfirmModal.vue`、加载中/空/错误三态容器 `TriStateList.vue`、Markdown 渲染与验证码组件；`layouts/` 定义页面级骨架——`AdminLayout.vue` 通过 `matchMedia('(max-width: 767px)')` 在桌面端使用固定 `Layout.Sider`（220/64 宽度切换）、移动端使用 `Drawer` 呈现 9+1 菜单项并锁背景滚动，复用 `AppHeader`；`HomeLayout.vue` 仅作为用户端底色容器；`BlankLayout.vue` 用于登录等居中空白页；`utils/importUrl.ts` 提供客户端导入 scheme 的 URL 编码拼接工具；顶层 `theme.ts` 暴露 `useTheme` composable，基于 `localStorage('theme')` 持久化并在 `document.documentElement` 上切换 Tailwind `dark` 类，同时计算 AntD `ConfigProvider` 的算法与主色；`style.css` 通过 `@tailwind base/components/utilities` 注入 Tailwind 并设置 `html/body/#app` 基础尺寸。依赖方向单向：组件 → stores/theme/utils，布局 → 组件，无反向依赖。
