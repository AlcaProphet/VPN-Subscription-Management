入口 `src/main.ts` 初始化 Vue 应用并挂载 Pinia store（auth、system）与 Vue Router；路由守卫在 `layouts/` 下的 AdminLayout/HomeLayout/BlankLayout 之间切换，将业务页面划分为 `views/admin/`（管理后台）与根级 `views/`（用户端）。所有视图通过 `api/` 下按后端域拆分的模块调用 REST 接口，复用 `components/` 中的通用 UI（Notify、ConfirmModal、TriStateList、MarkdownView），并通过 `theme.ts` 统一主题配置。测试套件 `tests/` 使用 Vitest + @vue/test-utils 对 store、路由守卫、axios 拦截器与视图进行覆盖，形成“外壳 → 路由/布局 → 视图 → API”的分层结构。
