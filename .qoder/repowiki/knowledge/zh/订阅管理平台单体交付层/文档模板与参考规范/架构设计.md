本模块由两个并列目录组成：`DocTemplates/` 存放项目级 Markdown 模板（AGENTS.template.md、Build.template.md、Issue.template.md、Design.template.md、Clashyaml.template.md、shadowrocket.template.md），作为 AI 助手与开发者生成当前活跃文档的蓝本；`Reference/` 存放面向设计决策的参考资料（SSpanel.md 对 SSPanel-UIM 源码的研究结论、Xray-Core-API.md 对 Xray Core API 的梳理）。模块本身不含可执行代码，仅通过模板变量（如 `<项目名>`、`<module/path>`）和交叉引用（如 AGENTS.template.md 中指向 DesignN/BuildN/IssueN 及 HistoryDocs/）驱动文档体系运转，依赖方向单向向外——被上层项目的 `HistoryDocs/`、`PlatformDocs/` 等目录消费。
