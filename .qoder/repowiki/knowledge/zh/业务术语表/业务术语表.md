### Xray 实例
- 定义：指一台运行中的 Xray-core 代理服务，拥有独立的 gRPC 管理面地址（unix socket 或回环 TCP）。一个实例可包含多个 inbound（如 vless+reality、vmess+ws、trojan），每个 inbound 有唯一 tag。面板通过 `xray_instances` 表管理实例列表，推送和采集均按实例维度隔离。
- 别名：实例、节点、Xray 服务

### inbound
- 定义：Xray 入站监听端口的逻辑标识，对应一个协议+传输组合（如 vless/reality、vmess/ws、trojan）。面板通过 `xray_inbounds` 表维护实例下的 inbound 清单（host/port/flow/network/security），装配器据此生成 Clash 节点行，用户激活时向每个 inbound 推送同一 UUID。
- 别名：入站、入站 tag、inbound tag

### 每用户专属订阅（方案 B）
- 定义：订阅内容形态：管理员维护一份模板（含 `{user_uuid}` 占位符），用户下载时系统按 Token 解析对应用户 UUID 并替换占位符，返回该用户独有的 YAML 配置。与「组内共享同一份订阅」不同，此方案下每个用户的订阅内容因 UUID 不同而唯一。
- 别名：方案B、per-user subscription、专属订阅

### 自然月配额
- 定义：流量配额周期跟随真实日历月份（如 2026-08），按月聚合 `traffic_records` 累计用量，超配额后仅移除 Xray 账号（面板用户保留），由管理员手动重置当月累计并重新推送。不采用自定义天数或定时清零表。
- 别名：月度配额、自然月流量

### 超限摘除
- 定义：配额检查任务发现用户当月累计用量超过配额后，调用 Xray `RemoveUserOperation` 移除其代理账号，但面板用户账号不受影响（仍可查看用量、续费恢复）。这是面板侧实现的软限策略，而非 Xray 内置能力。
- 别名：超限移除、配额超限动作

### 订阅装配器
- 定义：模块化组件，负责将规则、策略组、节点层等中间模型渲染为目标平台（Clash YAML、Shadowrocket .conf）的配置文本。对接 Xray 后，节点层数据源从管理员手填改为引用 `xray_inbounds` 表，动态生成节点行。
- 别名：装配器、订阅生成器、subscription assembler

### 占位标记
- 定义：订阅模板中用于注入节点的约定注释标记 `# {{xray_nodes}}`。装配器输出节点层时插入此处；下载时若无对应用户 UUID，则替换为注释行 `# 节点未开通，请联系管理员`，保证订阅链接始终可用且 YAML 语法完整。
- 别名：{{xray_nodes}}、节点注入点、占位符

### OIDC 提供商
- 定义：外部身份提供方类型，包括 Keycloak（带 Realm）、Auth0（Domain）、通用 OIDC（Base URL）以及 Mock（模拟模式）。切换提供商时，Realm 字段自动清空防止残留导致发现文档 URL 错误拼接。
- 别名：OIDC 类型、身份提供商、identity provider

### 验证码密钥明文存储
- 定义：站点密钥与服务端密钥不再经 AES-256-GCM 加密落库，改为明文存储。目的是允许停用后再启用、或切换不同验证码提供商（reCAPTCHA/Turnstile）时密钥不被损坏；存量密文需重新配置。
- 别名：明文密钥、captcha plain storage

### DEV/PROD 模式
- 定义：运行模式区分：dev 模式使用 `app-dev.db`，prod 模式使用 `app-prod.db`，两者均为持久化 SQLite 文件（存放在数据卷 `/data` 下），并非 dev 不持久化。切换模式会看到另一套独立数据库，未配置的那套进入 Setup 向导，易被误认为「数据清空」。
- 别名：开发模式、生产模式、APP_MODE

### 数据卷 vpn-data
- 定义：Docker 命名卷，挂载到容器内 `/data` 目录，承载全部持久化数据（SQLite 数据库、订阅文件、静态资源）。Compose 项目名前缀（如 `vpn-subscription-management_vpn-data`）由 Compose 自动添加，非代码决定。删除容器不会丢失数据，除非显式 `docker compose down -v`。
- 别名：vpn-data 卷、数据持久化卷
