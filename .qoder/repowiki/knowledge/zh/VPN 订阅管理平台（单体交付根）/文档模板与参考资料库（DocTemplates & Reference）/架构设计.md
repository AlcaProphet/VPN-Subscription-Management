模块由两个并列目录构成，无可执行代码，纯文档资产：
- `DocTemplates/`：存放四类 `.template.md` 文件（AGENTS.template.md、Build.template.md、Design.template.md、Issue.template.md），作为当前活跃文档的蓝本。每个模板通过尖括号占位符（如 `<项目名>`、`<module/path>`、`<INTERVAL>`）标记需替换内容，并在顶部元信息块中声明文档定位与优先级（AGENTS.md 为唯一强要求，DesignN/BuildN/IssueN 为非强制参考），并通过交叉引用链接到同级的 DesignN.md、BuildN.md、IssueN.md 及历史归档 `HistoryDocs/`。
- `Reference/`：存放面向设计决策的研究资料，包括 `SSpanel.md`（对 SSPanel-UIM 源码的速览与方案差距分析）和 `Xray-Core-API.md`（基于 v26.7.28 源码核验的 gRPC API 能力、硬约束、错误匹配表与订阅规范）。
依赖方向单向向外：被上层项目的 `HistoryDocs/`、`PlatformDocs/`、`DesignN.md`、`BuildN.md` 等消费；模板之间通过相对路径互相引用，形成「当前活跃 + 历史存档」的双轨文档生命周期。
