模块由三个并列子目录组成，分别承担进程入口、数据层演进与静态资源注入：
- `backend/cmd/server/main.go` 是程序唯一入口，按顺序完成：读取 APP_MODE/LOG_LEVEL/PORT/DATA_DIR/TRUST_PROXY/RESET_ADMIN_PASSWORD 等环境变量 → 初始化环形缓冲日志 → 打开 store（dev 用 app-dev.db，prod 用 app-prod.db）→ 调用 store.Migrate 执行 migrations.FS → 检测紧急模式（DB 损坏或 RESET_ADMIN_PASSWORD）→ 正常路径下装配 user/version/server/cron 并 Run HTTP 服务；异常路径统一走 runEmergencyMode 仅暴露系统状态/站点信息/应急端点。
- `backend/migrations/` 使用 `//go:embed *.sql` 将所有编号前缀的 .sql 文件（0001_init.sql ~ 1007_versions_filename.sql）嵌入为 `embed.FS`，供 store 在启动时按文件名排序增量迁移，保证单二进制分发。
- `backend/web/web.go` 使用 `//go:embed all:dist` 嵌入前端构建产物占位目录，容器构建时被真实 dist 覆盖，使最终二进制自带静态资源。
依赖方向单向：main 导入 internal/* 与本模块的 migrations/web，migrations 与 web 不反向依赖业务逻辑。
