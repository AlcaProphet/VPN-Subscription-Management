模块按职责分为两层：`frontend/src/views/admin/` 下的 `.vue` 文件是独立路由视图（基于 `<script setup>` + Ant Design Vue），每个文件对应一个管理子页面（PlatformsView、GroupsView、SubscriptionsView、ApprovalsView、RulesView、SharesView、VersionManageView、AssemblyView、LogsView、SettingsView、UsersView、PlatformEditView），负责列表展示、表单编辑、确认弹窗与导航；`frontend/src/api/*.ts` 是对后端 `/admin/*` 接口的薄封装，按领域拆分为 approval.ts、group.ts、platform.ts、rule.ts、share.ts、subscription.ts、system.ts、version.ts，统一通过 `@/api/request` 的 `http` 实例发起请求。依赖方向单向：视图 → api 层 → axios/http 拦截器，其中 system.ts 因无需鉴权直接复用原始 axios 实例调用 `/api/system/status`。视图之间不互相引用，仅通过 vue-router 跳转；通用 UI 能力（ConfirmModal、TriStateList、Notify）以组件形式复用，所有视图均通过 TriStateList 包裹表格/卡片以实现统一的 loading/empty 状态。
