- 路由通过 `meta.layout`（blank/home/admin）、`meta.public`、`meta.requiresAdmin` 等布尔/字符串标记表达权限与布局语义，而非硬编码路径判断。
- 所有页面组件采用 `() => import('@/views/...')` 语法进行路由级懒加载，以实现代码分割。
- Pinia store 使用 `defineStore('name', () => {...})` Composition API 风格定义，将响应式 state（ref/computed）与异步 action 一并返回。
- 需要鉴权的请求在路由守卫或组件中通过 `useAuthStore().token` 判断是否携带凭据，本地凭据持久化统一使用 localStorage key `token`。
- 系统状态与站点信息通过 `fetchStatus(force?)` / `fetchSiteInfo(force?)` 模式实现带 force 参数的单次缓存读取，避免重复网络请求。
