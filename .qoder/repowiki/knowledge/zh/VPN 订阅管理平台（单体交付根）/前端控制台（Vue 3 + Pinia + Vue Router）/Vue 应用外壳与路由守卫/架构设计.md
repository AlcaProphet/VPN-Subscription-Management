模块以 `main.ts` 为入口，创建 Vue 应用并挂载 Pinia 与 router；`App.vue` 通过 ant-design-vue 的 `ConfigProvider` 注入主题与中文 locale，并按 `route.meta.layout`（blank/home/admin）动态渲染对应 Layout 组件，同时监听 `systemStore.siteName/siteIconUrl` 设置浏览器标题与 favicon。

路由集中在 `router/index.ts`，按 public / user / admin 三段声明并通过 `meta.layout`、`meta.public`、`meta.requiresAdmin` 标记权限语义；所有页面组件使用 `() => import(...)` 实现路由级懒加载。`beforeEach` 守卫按 UI §7.2 顺序执行：emergency → configured → 登录态 → 登录页跳过 → 管理员角色校验（调用 `@/api/auth.me` 实时刷新用户信息），并在进入/离开时驱动自实现的 2px 顶部进度条。

状态层由 Pinia store 构成：`stores/auth.ts` 管理 token 与用户信息（持久化到 localStorage key `token`，并提供 login/register/logout action）；`stores/system.ts` 缓存 `/api/system/status` 与公开站点信息，暴露 `status`、`siteName`、`siteIconUrl` 供守卫与 App 共享。全局类型在 `vite-env.d.ts` 中声明 `UserInfo`、`SystemStatus`，被 stores 与路由守卫共用。依赖方向单向：main → App → router/stores → @/api/*，stores 不反向依赖视图。
