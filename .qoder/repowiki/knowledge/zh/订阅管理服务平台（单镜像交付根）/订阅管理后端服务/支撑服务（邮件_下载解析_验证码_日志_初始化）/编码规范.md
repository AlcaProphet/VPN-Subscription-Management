- 每个子包以 `Service` 结构体承载状态，并通过 `NewService(...)` 构造函数显式注入依赖（config、store、logger 等），不使用包级单例。
- 配置项统一以包级常量键名（如 `KeyHost`、`KeyProvider`、`KeyConfigured`）集中声明，并通过 `config.Service.Get/Set` 读写，敏感键在 `init()` 中调用 `config.RegisterSensitive` 登记。
- 错误语义对外暴露为包级 `var ErrXxx = errors.New("...")` 哨兵错误（如 `ErrTokenInvalid`、`ErrUnassigned`、`ErrAlreadyConfigured`），由接入层映射为 HTTP 状态码。
- 可降级/可选能力（SMTP 未配置、验证码密钥缺失、分享/规则表未迁移）一律返回 error 或跳过处理，不 panic、不阻断主流程，仅记录 warn 日志。
- 对外部输入做安全清洗：邮件头经 `sanitizeHeader` 去除换行防注入，下载文件名经 `SanitizeFilename` 过滤控制字符，URL 路径中的平台标识必须与 Token 绑定一致否则视为无效。
- 数据库访问统一通过 `store.DB().QueryRowContext/ExecContext` 并传入 `ctx`，失败分支用 `errors.Is(err, sql.ErrNoRows)` 区分空结果与真实错误。
